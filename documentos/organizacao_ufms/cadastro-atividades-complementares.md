Cadastro de Atividades Complementares
No campo de seleção Tipo de CCND, o usuário deve selecionar a opção Atividades Complementares e clicar no botão 'Continuar'.

Seção Atividades Complementares
Na seção Atividades Complementares, o sistema exibe as informações das Atividades Complementares:

Carga Horária (C.H.) total da componente do Projeto Pedagógico do Curso (PPC);
C.H. total realizada;
Pontuação;
C.H. total aprovada.
Essas informações não são editáveis pelo usuário.


A C.H. Total da Componente no PPC é a carga horária exigida pelo PPC que o usuário deve cumprir.

A C.H. Total Realizada na CCND é a soma das C.H. de atividades complementares cadastradas pelo usuário.

A Pontuação é o total de pontuação obtida pelo usuário depois da conversão da C.H. das atividades complementares cadastradas em pontos conforme a Tabela Base de Pontuação das Atividades Complementares do Curso.

A C.H. Total Aprovada é a quantidade de C.H. de atividades complementares aprovadas pela coordenação do curso do usuário.

Seção Atividades
Ao iniciar a CCND Atividades Complementares, o usuário precisa cadastrar pelo menos uma atividade complementar para salvar seu registro.

Para cadastrar uma atividade complementar, deve-se preencher na seção Atividades as seguintes informações: atividade, breve descrição, carga horária (se necessário) e anexar o certificado.

No campo Atividade, o usuário deve selecionar o tipo da atividade correspondente a que será cadastrada pela lista disponível;
No campo Breve descrição, deve-se descrever de forma sucinta, em até 255 caracteres, a atividade realizada;
Se o tipo de atividade complementar exigir o registro de carga horária, aparecerá o campo Informe a Carga Horária. Aqui o usuário deve inserir em números a carga horária realizada na atividade;
No campo Certificado, o usuário deve clicar no botão 'Escolher' arquivo e selecionar de seu dispositivo o comprovante da atividade realizada.
Após inserir todas as informações, deve-se clicar no botão '+Cadastrar atividade' para adicionar o registro da atividade no sistema.

Seção Minhas Atividades Complementares
Na seção Minhas Atividades Complementares, a listagem das atividades cadastradas é exibida.

O usuário pode utilizar o campo Pesquisar para buscar uma atividade complementar cadastrada.


A listagem utiliza os seguintes campos: atividade, descrição, carga horária, pontuação, situação e ações.

Na coluna Atividade, o sistema apresenta o tipo de atividade complementar;
Na coluna Descrição, o sistema apresenta a breve descrição registrada pelo usuário;
Na coluna Carga Horária, o sistema apresenta a carga horária da atividade registrada pelo usuário;
Na coluna Pontuação, o sistema apresenta a pontuação correspondente à atividade;
Na coluna Situação, o sistema apresenta a situação atual da atividade se essa foi analisada, aprovada ou recusada pela análise da coordenação do curso.

Salvamento de atividades
Caso o usuário deseje salvar as atividades cadastradas para adicionar outras atividades posteriormente ou remover as atividades já cadastradas, ele deve clicar no botão 'Salvar' na parte inferior da tela. Em seguida, ele será redirecionado para a tela inicial de listagem das CCNDs e a situação da CCND Atividades Complementares será alterada para 'Pendente'.


Envio para aprovação
Após a pontuação atingir a C.H. total da componente no PPC, o usuário pode submeter as atividades cadastradas para análise da coordenação, clicando no botão  na parte inferior da tela. Ao clicar no botão 'Enviar para aprovação', uma janela aparecerá para confirmação da ação pelo usuário. Caso o usuário concorde em enviar as atividades para análise da coordenação, ele deve clicar no botão 'Enviar' para aprovação da janela. Uma vez enviada para aprovação, o usuário não poderá mais inserir/remover atividades complementares. Caso o usuário queira cancelar o envio das atividades à análise da coordenação, ele poderá clicar no botão Fechar para cancelar a ação.

Se o usuário enviar para aprovação mas não tiver atingido a pontuação necessária, a mensagem de erro "você não possui a pontuação necessária para enviar a CCND para aprovação" aparecerá na parte superior da tela.
Se o usuário enviar para aprovação e tiver cumprido a pontuação necessária, o usuário será redirecionado para a tela inicial de listagem das CCNDs, a mensagem "a CCND foi enviada para aprovação" aparecerá na parte superior da tela e a situação da CCND Atividades Complementares será alterada para Aguardando Análise
