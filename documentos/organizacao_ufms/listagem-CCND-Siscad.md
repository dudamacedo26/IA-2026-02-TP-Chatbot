Listagem das Componentes Curriculares Não Disciplinares (CCNDs)
As Componentes Curriculares Não Disciplinares (CCNDs) encontram-se no menu  CCND.

Essa página apresenta a listagem de todas as CCNDs realizadas pelo usuário ao longo de seu curso.


Filtros:
O usuário pode filtrar suas CCNDs pelo: título, tipo de CCND, previsão de início e previsão de término.

No filtro Título, o usuário pode digitar o título completo ou alguma palavra-chave para realizar a busca. Com isso, o sistema realizará a filtragem sobre os títulos dos trabalhos realizados nas CCNDs;
No filtro Tipo de CCND, o usuário pode selecionar uma opção de tipo de CCND para o sistema filtrar os trabalhos realizados nas CCNDs. As opções disponíveis são: Atividades Complementares, Atividades de Extensão, Atividades Orientadas de Ensino e Trabalho de Conclusão de Curso;
É possível utilizar mais de um tipo de filtro para buscar as CCNDs realizadas.

Ao inserir os dados no(s) campo(s) de filtro, deve-se clicar no botão 'Buscar' para o sistema realizar a filtragem.

Caso queira apagar todos os dados inseridos no filtro, clique no botão 'Limpar'.


No campo pesquisar, o usuário pode digitar um termo para o sistema filtrar as CCNDs que utilizam o termo buscado.


Listagem de CCNDs
Para iniciar uma nova CCND, deve-se clicar no botão '+Iniciar CCND'.

No campo Pesquisar, o usuário pode digitar um termo para o sistema filtrar as CCNDs que utilizam o termo buscado.

Na listagem de CCNDs, é apresentada uma lista das CCNDs realizadas pelo usuário. Para cada CCND, é exibido: título, tipo, previsão de início, previsão de término, situação e botões de ações.

A coluna Título apresenta o título da CCND cadastrada;
A coluna Tipo apresenta o tipo da CCND, que pode ser: Atividades Complementares, Atividades de Extensão, Atividades Orientadas de Ensino ou Trabalho de Conclusão de Curso;
A coluna Previsão de Início apresenta a data em que a CCND foi ou será iniciada;
A coluna Previsão de Término apresenta a data em que a CCND está planejada para terminar. Atividades Complementares e Atividades de Extensão não apresentam previsão de término, as quais deixam esta coluna vazia;
A coluna Situação apresenta a situação atual de cada CCND;
A coluna Ações apresenta botões de acordo com a situação de cada CCND.
O botão (ícone azul com um olho) Visualizar CCND serve para exibir as informações da CCND em detalhes;
O botão (ícone amarelo com um bloco de notas) Editar CCND serve para o usuário retificar as informações de uma CCND;
O botão (ícone vermelho com uma lata de lixo) Remover CCND serve para excluir o cadastro da CCND;
O botão (ícone verde com uma seta para cima) Finalizar serve para o usuário submeter o cadastro à aprovação do responsável pela CCND.
A lista de CCNDs poderá ser exportada em formato excel clicando em 'Exportar Excel' ou em formato PDF clicando em 'Exportar PDF'.
